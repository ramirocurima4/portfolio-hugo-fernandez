Portfolio Dinámico: Hugo Fernández - Arte Creativo & Carnaval
¡Hola! Soy Ramiro Curimá, estudiante de segundo año de la Tecnicatura en Desarrollo de Software en San Roque, Corrientes, Argentina.

Este es uno de mis primeros proyectos integrales (Full-Stack) y tiene un valor inmenso para mí porque une mis habilidades técnicas con una de mis mayores pasiones: la cultura del carnaval correntino.

Vengo de una formación secundaria como técnico en reparación de equipos electromecánicos, lo que me enseñó a entender cómo funcionan las estructuras desde adentro. Hoy, aplico esa misma lógica al código. Diseñé y desarrollé esta plataforma web a medida para mi tío, Hugo Fernández, un referente en la coordinación general y realización de vestuarios de carnaval, con el objetivo de llevar su trayectoria "desde el barrio y nuestro pueblo, hasta las grandes pasarelas del Nolo Alías".

🚀 Sobre el Proyecto
Lo que comenzó como una página estática, evolucionó hacia una aplicación web dinámica con su propio sistema de gestión de contenidos (CMS). La plataforma permite administrar el catálogo de trajes, hidratar el DOM dinámicamente y gestionar interacciones sociales sin depender de servicios de terceros.

Stack Tecnológico:

Backend: Python y Flask (Server-Side Rendering para SEO y Open Graph).

Base de Datos: SQLite (ligera, embebida y sin necesidad de configuraciones externas).

Frontend: HTML5, CSS3, JavaScript Vanilla (Fetch API).

UI/UX: Diseño Mobile-First con implementación de scroll-snap vertical (estilo feed inmersivo) para mejorar la retención de usuarios en dispositivos móviles.

Este proyecto representa mi transición hacia el desarrollo de software profesional, creando código que resuelve problemas reales, impulsa negocios locales y, sobre todo, celebra el ADN de nuestro carnaval.

🛠️ Instrucciones de Ejecución Local
Si necesitas correr este proyecto en otra computadora, sigue estos pasos:

Clonar el repositorio: git clone https://github.com/TuUsuario/portfolio-hugo-fernandez.git

Entrar a la carpeta: cd portfolio-hugo-fernandez

Crear entorno virtual: python -m venv venv

Activar el entorno:

En Windows: venv\Scripts\activate

En Mac/Linux: source venv/bin/activate

Instalar Flask: pip install Flask werkzeug

Encender el servidor: python app.py

Ver la página: Abre tu navegador y entra a http://127.0.0.1:5000

Panel de Admin: Entra a http://127.0.0.1:5000/admin para subir nuevos trajes y moderar comentarios.
