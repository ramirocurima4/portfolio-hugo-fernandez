# Carpeta de Imágenes: /assets/img/

Ubicá aquí las fotografías oficiales en alta resolución de los trajes, espaldas, coronas y comparsas.

### Estructura sugerida:
- `/trajes/`: Fotos de trajes completos y detalles para las galerías.
- `/hugo/`: Fotos de Hugo en el taller o desfilando.
- `/comparsas/`: Logos y fotos de las comparsas (Arandú Beleza, Sapucay, Ará Berá).
